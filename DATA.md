# DATA: what training data this repository ships, and what it does not

Every data file here is plain JSON lines, one row per line, each file under 25 MB, listed with its md5. Nothing here
is an evaluation set, a held-out fold, a hidden-state dump or a model weight.

| what | where | rows | size | details |
|---|---|---|---|---|
| bank templates + generators (all banks) | `banks/` | regenerated by the make scripts | small | `banks/README.md` |
| generated bank rows (subrole, divrole2, v5x C1-C6, v5div, v6ms closed rounds) | `data/banks/` | 114,220 in 29 files | 308 MB (uncompressed) | `data/DATA_banks.md`: per file source, languages, rows, bytes, md5, generator md5, fold columns, license |
| real word problems (wild rows): ASDiv + MathQA train, folds 1-4 | `data/wild/` | 7,497 in 8 files | 13 MB | `data/wild/README.md`: per file rows and md5, how rows were chosen, columns, licenses |
| more training rows: wild Ape210K / Math23K / MAWPS / MathQA / ASDiv + the project's generated sets (v1-v5, v24, bbx, wildbig, BIG-bench arithmetic) | `data/more/` | 207,332 in 40 files | 340 MB | `data/more/README.md`: per source rows, languages, licenses; train split only |

`python banks/make_bank_data.py` checks every shipped row file against `data/banks/ROWS.md5`.

## Using bank rows with `defuse/`

Bank rows name their fields differently from the def-use rows; `defuse/bank_rows.py` adapts them without touching
the text or the answer, and assigns `fold` from a bank fold column you choose (one value held out as fold 5):

```python
from defuse.bank_rows import to_defuse_row
row = to_defuse_row(bank_row, fold_key=("v6", "tmpl_fold"), heldout_value=5)        # v6ms: held-out templates
row = to_defuse_row(bank_row, fold_key=("v6", "lang_fold"), heldout_value=5)        # v6ms: held-out languages
row = to_defuse_row(bank_row, fold_key="fold", heldout_value=4, values=(0, 1, 2, 3, 4))   # subrole / divrole2
```

The project used v6ms with a rotation (each language block held out once); a single fixed held-out value is the
simple version of that. The v6ms rounds G1 (chains) and G3 (varied question types) carry an infix equation and parse
exactly; the G2 rounds (conditionals, selection) carry their program only in `v6.program` (with guards), which the
def-use grammar does not express, so the parser reports `no_equation` for them (10,638 of the 31,716 shipped
at-most-5-numeral v6ms rows).

## Wild training rows (real word problems): `data/wild/`

The def-use readers in the project were fitted on folds 1-4 of a pool of public word problems with gold equations.
The rows from the two sources whose license and train / test status are clear are shipped in `data/wild/`
(`data/wild/README.md` has the details):

| source | license (as stated by the source) | shipped | rows (folds 1 / 2 / 3 / 4) |
|---|---|---|---|
| ASDiv | CC BY-NC 4.0 (non-commercial, attribution) | yes, folds 1-4 (it has no official test split); the license file travels with the rows | 270 / 227 / 310 / 294 = 1,101 |
| MathQA | Apache-2.0 | yes, its train split only, folds 1-4 | 1,572 / 1,711 / 1,485 / 1,628 = 6,396 |
| MAWPS | none stated; the original site is offline | in `data/more/` (private use, 2026-10-20) | - |
| Math23K | none stated (the copy used is a third-party repository) | in `data/more/` (private use, 2026-10-20) | - |
| Ape210K | the repository's README gives a license for the code only, none for the data | in `data/more/` (private use, 2026-10-20) | - |
| GSM8K train | MIT | no (the project never fitted the def-use readers on it) | - |

So the project's readers saw about 98,600 fit rows from five sources per layer; you have 7,497 of them (the two
shippable sources). Expect your readers to be weaker than the project's for that reason alone; RUN_ON_THOR.md, step 7,
says how to read the comparison.

* **Folds 1-4 only.** Fold 5 (the held-out fold) and fold 6 (the source datasets' official test / validation splits
  and every row linked to them) are not shipped and never will be, and the loader refuses any row whose `fold` is 5
  or 6 (`tests/test_wild_data.py` checks every shipped row). MathQA's own dev and test rows are left out even where
  they sit in folds 1-4, and so are rows the project linked as near-duplicates of an evaluation row.
* **No host outcomes.** The rows carry no host's answers and no host-right / host-silent labels: you make your own with
  `--greedy 12` when you dump (`defuse/run.py`, `host_fields`).
* **Never:** any evaluation or held-out set (the GSM8K test family, MGSM, AfriMGSM, SVAMP, the project's fresh held-out
  set), and no bank that is still being generated.

## What you may fit on

| rows | fit, choose settings, fit the gate | hold out / score once |
|---|---|---|
| `data/wild/*/fold1-4.jsonl` (all 7,497; `data/wild/MANIFEST.jsonl` lists them) | yes, all of them; the `fold` column is the project's | nothing here: the project's fold 5 is not shipped. If you want a held-out number of your own, pick one fold (say 4) BEFORE you fit, fit on the other three, and score it once |
| `data/banks/` rows | yes, every value of the fold column you fit on | the one value you hold out (`bank_rows.to_defuse_row(..., heldout_value=...)`; `data/DATA_banks.md` lists each file's fold columns) |

## More training rows: `data/more/` (added 2026-10-20)

207,332 rows from the project's arithmetic data, every one of them a **train** row of the project's in-force split
rules (the AMEND5b overlay, 53 manifests, `MANIFESTS.md5` file md5 `529502974a7073473fae45b3c50b6bf3`). **Training
split only: build your own held-out fold from it, as with folds 1-4.** The row's `fold` (1-4) is a hash of its lineage
family, so you can hold one out; `python -m defuse.more --out rows.jsonl` md5-checks the files and refuses any row that
is not `train` in the shipped manifests (`tests/test_more_data.py` checks the same). Folds 5 and 6 are not in these files.

|---|---:|---|---|

**Licenses and this repository.** The repo owner decided on 2026-10-20 that this repository is private and the rows are
for his and his students' own use, so sources without a clear data license (Ape210K, Math23K, MAWPS) are included;
each source folder has a `LICENSE.md` with the license, the URL and the attribution. Clear or delete those folders
before the repo or any of its data is made public; ASDiv stays non-commercial.

Rows with more than 5 digit runs are in the generated sets (v24 542, v4 2,306, v5 15,210); filter on the manifest's
`n_runs`. Rows the reader cannot express (`gold_status` other than `exec_exact`) are shipped and labelled.
