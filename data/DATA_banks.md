# Shipped training rows: `data/banks/`

The generated rows of the training banks, as plain JSON lines (one row per line, UTF-8), so you can train on them
without running a generator. Every file is under 25 MB. Each is byte for byte what the bank's generator writes
(checked against the bank's own SHIP md5 file in `banks/<bank>/` first), except where the notes say SPLIT or
FILTERED. The md5 of every file is in `data/banks/ROWS.md5`; to check them:

```bash
python banks/make_bank_data.py              # md5 of every file below, and of the joined v5div parts (seconds)
python banks/make_bank_data.py --rebuild    # regenerate every bank in a temporary folder and compare (about 7 minutes)
python -m pytest -q tests/test_banks_shipped.py
```

The banks themselves (what each row means, how the templates were written and verified) are described in
[`banks/README.md`](../banks/README.md). **License:** synthetic, written for this project; MIT like the repo.

Totals: 29 files, 114,220 rows, 322,921,154 bytes (308 MB). Languages: subrole and divrole2 English; v5x the 36
languages am bg bo cs eu fi gu ha hu hy is ka kk km kn la lt ml mn mr ms my ne pa ro si sk sq sr sv te tl ur uz yo
zu (six per chunk); v5div the 25 of v5 (ar bn de el en es fa fr he hi id it ja ko nl pl pt ru sw ta th tr uk vi zh);
v6ms 20 (ar bn de el en es fa he hi id ja ko pl ru sw ta th tr vi zh).

## What is deliberately not here

* `v3_61`, `v4`, `v4wild`, `v5`: their generators regenerate them byte for byte in a minute (`python banks/make_banks.py`,
  `python banks/make_v5.py`), so their rows are not duplicated here.
* Anything a project result is scored on: `subrole_g3` (fold -2), divrole2's reference rows (fold -1), the last chunk of
  v5div (R4), and every real-problem test set.
* The abstain banks AB1 and ABX (templates only, in `banks/abstainbank*/`; their filling tool is not shipped) and the
  audience demo bank (`banks/audience/gen_audience_v2.py` writes it in a second).
